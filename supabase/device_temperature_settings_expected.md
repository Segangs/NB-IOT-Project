# 센서별 온도 설정 계약

- 설정 단위: 기기에 매핑된 TMP 센서별 개별 설정
- 상한 온도: `-50.0..25.0℃`, `0.5℃` 단위
- 최대 알림 횟수: 센서별 `1..3`, 미설정 기본값 `3`
- 재알림 간격: 기존 `20분` 고정
- 저장 원자성: 제출 센서 중 하나라도 잘못되면 전체 미변경
- 접근 범위: 소유 사용자·영업장·기기·TMP 센서 일치
- 설정 감소: 진행 중 incident의 이후 추가 알림 즉시 중단
- 설정 증가: 마지막 알림 후 20분 조건 충족 시 이후 회차 허용
- 상한 적용: 저장 뒤 들어오는 새 온도 데이터부터 서버 판단 반영
- Pico 적용: 다음 정기 config pull에서 새 상한 수신
- 권한: RLS 활성, service role 전용 RPC
- rollback: 센서별 횟수 제거 및 기존 최대 3회 trigger 복원
- rollback 제한: 이미 변경된 `USER_SENSOR.setTmpUpLimit` 상한 온도 자동 복원하지 않음
