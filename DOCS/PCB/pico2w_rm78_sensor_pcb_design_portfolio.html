Pico 2 W · RM78-1 LTE-M · DS1129-04 센서 허브 PCB 설계 문서

1. 문서 개요

본 문서는 Raspberry Pi Pico 2 W, RM78-1 LTE-M 모뎀, DS1129-04 듀얼 RJ45 커넥터, DS18B20 온도센서, SPH0645LM4H I2S MEMS 마이크, LCD1602 I2C 표시장치, 8002A 경보 스피커, IP5306 전원 모듈, LTC2954CTS8-1 전원버튼 컨트롤러, 전자식 전원 스위치 모듈을 통합하기 위한 회로 및 PCB 설계 과정 정리문서임.

설계 목적은 3m UTP 케이블을 통해 외부 센서 보드의 온도 데이터와 공기 중 기계음을 안정적으로 수집하고, LTE-M 통신을 통해 원격 시스템과 연동하며, 배터리 기반 전원관리와 안전 종료 기능을 구현하는 것임. 단순 센서 연결 보드를 넘어서 전원 안정성, 신호 무결성, 커넥터 호환성, 추후 유지보수성, 포트폴리오 공개 가능성을 고려한 통합 제어 PCB 설계가 핵심 목표임.

본 설계의 주요 특징은 일반 RJ45 8P8C 소켓을 이용한 센서 케이블링, 이더넷 MagJack 배제, I2S 클럭 공유 구조, DS18B20 1-Wire 풀업 구성, GPIO 기능군 분리, LTC2954 기반 안전 종료 전원관리, IP5306 기반 배터리 충전·부스트 전원 구성, 모뎀 송신 시 전원 흔들림 완화, 초보 납땜 가능성을 고려한 모듈형 부품 활용임.

2. 전체 시스템 구성

전체 시스템은 센서 입력부, MCU 제어부, LTE-M 통신부, 표시 및 경보부, 전원관리부, 외부 인터페이스부로 분리하여 설계함.

3. 회로설계 과정

3.1 RJ45 커넥터 선정 과정

초기에는 HR911105A RJ45 커넥터 사용 가능성을 검토함. HR911105A는 일반 RJ45 커넥터가 아니라 이더넷용 절연 트랜스와 초크가 내장된 MagJack 계열 부품임. 내부에 변압기가 포함되어 있으므로 DC 성분과 일반 GPIO High/Low 신호를 정상적으로 통과시키지 못하는 구조임. 따라서 Pico의 GPIO, 1-Wire, I2S, 전원선을 그대로 UTP 케이블로 전달하는 용도에는 부적합한 부품으로 판단함.

해결책으로 변압기 없는 일반 RJ45 8P8C 소켓을 사용하기로 결정함. 최종 커넥터는 DS1129-04 듀얼 RJ45 포트로 선정함. 이 부품은 2개 RJ45 포트를 하나의 패키지에 포함하며, 각 포트에 LED 2개를 포함하는 구조임. 센서 2세트를 독립적으로 연결할 수 있고, PCB 면적을 줄이며, 케이스 외부 포트 구성도 단순하게 만들 수 있는 장점이 있음.

3.2 DS1129-04 풋프린트 검토 과정

DS1129-04와 유사한 중국산 RJ45 부품은 EasyEDA에서 정확한 제조사 모델명으로 검색되지 않는 문제가 있었음. 판매 페이지에 표시된 긴 Part Number는 실제 CAD 라이브러리 검색용 부품명이 아니라 주문 코드 또는 옵션 코드에 가까운 형식이었음. 따라서 데이터시트 이미지와 PCB Layout 치수를 기준으로 풋프린트를 검토함.

최종적으로 확인된 핀 구조는 오른쪽 포트가 1~8번, 왼쪽 포트가 9~16번, 오른쪽 포트 LED가 17~20번, 왼쪽 포트 LED가 21~24번, 실드 고정핀이 25~26번인 구조임. 풋프린트 화면에서 오른쪽 포트의 핀 배열은 윗줄 8, 6, 4, 2와 아랫줄 7, 5, 3, 1로 나타나는 지그재그 구조임. EasyEDA에서는 물리적 위치가 아니라 심볼 핀 번호와 Net Label 기준으로 연결하는 것이 중요함.

3.3 센서 신호 배선 설계 과정

센서 구성은 각 RJ45 포트마다 DS18B20 온도센서 1개와 SPH0645LM4H I2S MEMS 마이크 1개를 연결하는 방식으로 설계함. DS18B20은 VDD, GND, DATA 3가닥을 사용하고, SPH0645LM4H는 VDD, GND, BCLK, LRCLK, DOUT, SEL 중 SEL을 센서보드에서 GND에 고정하여 5가닥만 RJ45로 전달하는 구조로 결정함.

SPH0645LM4H의 SEL은 채널 선택 핀으로, 단일 마이크 운용 시 센서 보드에서 GND에 묶어 Left 채널로 고정하는 방식이 가장 단순함. SEL을 RJ45 Pin8로 전달하는 방법도 검토했으나, 실제 운용에서는 채널 변경 필요성이 낮고 배선 복잡도가 증가하므로 Pin8은 NC로 남기는 방식으로 결정함.

3.4 UTP Pair 고려 과정

CAT5e/CAT6 UTP 케이블은 핀 번호가 순서대로 꼬이는 것이 아니라 1-2, 3-6, 4-5, 7-8이 각각 꼬임쌍을 구성함. 초기 배선안은 단순히 1번부터 8번까지 전원, 접지, 온도, 마이크 신호를 순서대로 배치하는 구조였으나, 이 경우 I2S BCLK와 저속 데이터가 같은 Pair에 배치될 수 있어 신호 무결성 측면에서 불리함.

최종 배선은 BCLK를 GND와 같은 Pair인 4-5에 배치하고, DOUT과 TEMP DATA를 3-6 Pair에 배치하며, LRCLK를 7번에 배치하는 방식으로 결정함. BCLK는 가장 빠른 클럭 신호이므로 반드시 GND와 인접 또는 같은 꼬임쌍에 배치하는 것이 중요함. DOUT과 TEMP DATA가 같은 Pair를 사용하는 것은 완벽한 구성은 아니지만, BCLK에 비해 상대적으로 간섭 위험이 낮고 8가닥 제한 내에서 가장 현실적인 타협안임.

6. 전원관리 회로 설계

6.1 전원관리 목표

전원관리 목표는 사용자가 푸시버튼을 누르면 시스템이 켜지고, 동작 중 다시 버튼을 누르면 Pico가 안전 종료 절차를 수행한 뒤 전체 시스템 전원을 차단하는 것임. 기존 라커스위치 방식은 ON/OFF 상태 유지형이라 LTC2954의 PB 입력과 궁합이 좋지 않고, 안전 종료 구현이 복잡해지는 문제가 있었음. 최종적으로 순간 푸시버튼과 LTC2954 전원버튼 컨트롤러를 사용하는 방식으로 결정함.

6.2 전원 Net 분리

전원은 항상 살아있는 전원과 시스템 동작 전원으로 분리함.

Net 이름의미연결 대상

+5V_SYS전자식 전원 스위치 이후의 시스템 5VPico VSYS, RM78-1, LCD, 센서 전원, 8002A 앰프

핵심 원칙은 꺼져야 하는 모든 부품을 +5V_SYS 뒤쪽에 배치하는 것임. RM78-1 LTE 모뎀, LCD, 8002A 앰프, 센서 전원, Pico VSYS는 모두 +5V_SYS에 연결함. +5V_IP5306에는 LTC2954와 전자식 전원 스위치 입력만 연결함.

사용 부품은 IN, SW, OUT, GND 네 단자를 가진 3V~25V 2A 전자식 전원 스위치 모듈 B버전, 즉 NO 스루홀 버전으로 결정함. 이 모듈은 SW가 High일 때 IN과 OUT을 연결하고, SW가 Low일 때 차단하는 단순 로드스위치 역할을 수행함.

8. 각 부품별 기능과 연결 의도

8.1 Raspberry Pi Pico 2 W

Pico 2 W는 전체 시스템의 중앙 제어기로 사용함. LTE 모뎀 제어, I2S 마이크 데이터 수집, DS18B20 온도값 읽기, LCD 표시, LED 상태 표시, 경보음 PWM 출력, 안전 종료 로직을 모두 담당함. GP0~GP4는 LTE 모뎀 주변 기능으로 묶어 배치하고, 센서 신호는 GP18~GP22 및 GP26으로 이동하여 노이즈원과 물리적으로 분리함.

8.2 RM78-1 LTE-M 모듈

RM78-1은 LTE-M 통신을 담당하는 모듈임. UART TX/RX는 GP0/GP1에 배정하고, WAKEUP, RESET, PWRON 등 제어선은 GP2/GP3 계열에 배정함. TXON 신호는 RM78-1에서 Pico GP5로 입력받고, TXON 표시 LED는 Pico GP28로 별도 제어함. 모뎀은 송신 시 순간 전류가 커질 수 있으므로 +5V_SYS 근처에 470µF~1000µF 캐패시터를 병렬로 배치함.

8.3 DS1129-04 듀얼 RJ45

DS1129-04는 외부 센서 케이블 연결용 포트임. 각 포트는 DS18B20 1개와 SPH0645LM4H 1개를 연결하는 센서 허브 인터페이스로 사용함. RJ45 내부 LED 4개는 모두 사용하여 포트별 상태 표시 기능을 제공함. 실드 핀은 GND에 연결하거나 0Ω 저항을 통해 GND에 연결하여 EMI 및 접지 문제에 대응할 수 있도록 함.

8.4 DS18B20 온도센서

DS18B20은 1-Wire 디지털 온도센서임. 각 포트마다 DATA 1가닥을 Pico에 독립 연결함. DATA 라인은 5.1kΩ 저항으로 3.3V에 Pull-up함. 원래 4.7kΩ이 일반적이나 5.1kΩ도 3m UTP 조건에서 실사용 가능한 값으로 판단함.

8.5 SPH0645LM4H I2S 마이크

SPH0645LM4H는 I2S 출력 MEMS 마이크임. BCLK와 LRCLK는 두 마이크가 공유하고, DOUT만 마이크별로 분리함. 이를 통해 GPIO 사용량을 줄이고 I2S 구조를 단순화함. 마이크 SEL 핀은 센서 보드에서 GND에 직접 연결하여 Left 채널로 고정함. BCLK는 UTP Pair 4-5에서 GND와 함께 전달하여 신호 무결성을 높임.

8.6 LCD1602 I2C

LCD1602는 I2C 인터페이스로 GP16 SDA, GP17 SCL에 연결함. LCD는 시스템 상태, 온도값, LTE 상태, 안전 종료 메시지를 표시하는 용도임. 전원은 +5V_SYS에서 공급하여 시스템 OFF 시 함께 꺼지도록 구성함.

8.7 8002A 앰프 스피커

8002A 앰프 스피커는 경보음 출력용으로 사용함. Pico GP6에서 PWM 신호를 출력하고, 1kΩ 직렬 저항을 거쳐 8002A IN에 입력하는 방식으로 구성함. 전원은 +5V_SYS에 연결하여 시스템 OFF 시 대기전류를 제거함. 마이크 입력부와 8002A 출력부는 PCB에서 가능한 멀리 배치하여 오디오 피드백과 노이즈 유입을 줄이는 것이 설계 의도임.

8.8 IP5306 전원 모듈

IP5306은 18650 리튬 배터리 충전, 보호, 5V 부스트 출력을 담당함. IP5306의 VOUT은 +5V_IP5306으로 명명하고 LTC2954와 전자식 전원 스위치 입력에만 연결함. 기존에는 IP5306 출력이 Pico와 모뎀에 직접 연결되는 구조였으나, 안전 종료 후 전원 차단 기능을 위해 전자식 전원 스위치 앞단 전원으로 역할을 제한함.

8.9 LTC2954CTS8-1

LTC2954CTS8-1은 푸시버튼 기반 전원관리 IC임. 사용자가 버튼을 누르면 EN을 통해 전자식 스위치를 켜고, 동작 중 버튼을 다시 누르면 INT로 Pico에 종료 요청을 전달함. Pico가 종료 작업을 마친 후 KILL 신호를 보내면 LTC2954가 EN을 끄고 시스템 전원을 차단함. 전원 케이블을 뺐다가 다시 꽂아도 기본적으로 시스템은 OFF 대기 상태가 되며, 사용자가 푸시버튼을 눌러야 켜지는 구조임.

8.10 전자식 전원 스위치 모듈

전자식 전원 스위치 모듈은 LTC2954 EN 신호에 따라 +5V_SYS를 공급하거나 차단하는 로드스위치 역할임. B버전 NO 스루홀 제품을 사용하며, 단자는 IN, SW, OUT, GND 네 개임. IN은 +5V_IP5306, OUT은 +5V_SYS, SW는 LTC2954 EN, GND는 공통 GND에 연결함. 모듈형 부품으로 사용하여 AO3401 MOSFET 단품 회로보다 납땜과 검증 난이도를 낮춤.

9. PCB 설계 과정

9.1 PCB 크기 산정

초기 권장 PCB 크기는 100mm × 80mm임. 80mm × 60mm도 이론적으로 가능하지만, Pico 2 W, RM78-1, IP5306, MP1584EN, DS1129-04, 전원 스위치 모듈, 8002A, 대용량 캐패시터, 외부 커넥터, 나사홀을 모두 고려하면 초보 설계에서는 지나치게 빡빡함. 100mm × 80mm로 시작하여 배치 안정성을 확인한 뒤 필요하면 90mm × 70mm까지 줄이는 방식이 적합함.

9.3 신호 배선 원칙

I2S BCLK는 가장 민감한 고속 신호이므로 가능한 짧게 배선하고, GND와 가까이 유지함. 마이크 DOUT 라인과 LRCLK 라인은 LTE 모뎀 전원선과 8002A 스피커 출력선에서 떨어뜨려 배치함. DS18B20 DATA 라인은 저속 신호지만 3m UTP 외부 케이블을 사용하므로 Pull-up 저항을 MCU 보드 쪽에 배치함. 업로드된 회로도에서는 I2S 관련 라인에 47Ω 직렬저항이 추가되어 있으며, 이는 3m UTP 케이블에서 신호 반사와 링잉을 완화하기 위한 보강으로 반영함.

9.4 전원 배선 원칙

+5V_IP5306와 +5V_SYS를 명확히 분리함. +5V_IP5306는 항상 살아있는 전원으로 폭을 적절히 확보하되, 연결 대상은 LTC2954와 전자식 전원 스위치 IN에 제한함. +5V_SYS는 Pico, LTE, LCD, 센서, 앰프를 공급하므로 굵은 전원 패턴을 사용함. 모뎀과 앰프 전원 패턴은 가능하면 넓게 설계하고, GND 리턴 경로를 짧고 굵게 유지함.

9.5 모듈형 부품 풋프린트 처리

전자식 전원 스위치 모듈은 명확한 모델명이 없고 EasyEDA 라이브러리 검색이 어려움. 따라서 PCB에는 전자식 스위치 전용 심볼 대신 4핀 커넥터 또는 4개 패드로 처리함. 핀헤더 또는 와이어 연결 방식으로 IN, SW, OUT, GND를 연결하면 모듈 교체가 쉽고, 향후 다른 로드스위치 모듈로 변경할 때 PCB 수정 부담이 줄어듦.

13. 회로 설계 의도 요약

본 회로는 “센서 신호 안정성”, “LTE 통신 안정성”, “배터리 전원 안전성”, “초보 제작 가능성” 사이의 균형을 목표로 설계함. 고속 I2S 신호는 UTP Pair와 GND 리턴을 고려하여 배치하고, DS18B20은 독립 DATA와 Pull-up 저항으로 안정성을 확보함. LTE 모뎀은 전류 피크를 고려하여 대용량 캐패시터를 근접 배치함. 전원부는 IP5306의 상시 5V와 전자식 스위치 이후 시스템 5V를 분리하여 안전 종료 후 전원 차단이 가능하도록 구성함.

LTC2954는 단순 버튼 입력을 전원관리 시퀀스로 변환하는 핵심 부품임. 이를 통해 사용자는 푸시버튼 하나로 ON/OFF를 조작하고, Pico는 OFF 요청을 받은 뒤 필요한 종료 절차를 수행할 수 있음. 라커스위치 방식보다 구현이 단순하고, 전원 버튼 컨트롤러의 원래 사용 목적에도 부합하는 구조임.

최종 설계는 포트폴리오와 GitHub 공개를 고려하여 기능 블록, Net 이름, GPIO 배정, 부품 역할을 명확히 분리함. 향후 펌웨어 구현 시에도 GPIO 테이블과 Net 이름을 그대로 코드 상수명으로 매핑할 수 있는 구조임.

15. 최종 결론

본 설계는 Pico 2 W 기반 LTE-M 센서 허브를 구현하기 위한 통합 회로 및 PCB 설계안임. HR911105A MagJack의 부적합성을 확인하고 일반 8P8C RJ45 기반 센서 인터페이스로 변경한 점, DS1129-04 듀얼 포트를 센서 2세트 입력으로 활용한 점, SPH0645 I2S 신호의 UTP Pair 배치를 재설계한 점, DS18B20 Pull-up과 3m 케이블 조건을 반영한 점, LTE 모뎀과 앰프 전원 노이즈를 고려한 점, LTC2954 기반 안전 종료 회로를 추가한 점이 핵심 성과임.

최종 PCB는 +5V_IP5306와 +5V_SYS를 분리하고, 모든 실제 시스템 부하를 전자식 전원 스위치 뒤쪽에 배치하는 구조임. 푸시버튼 입력은 LTC2954가 처리하고, Pico는 INT와 KILL만 담당함. 이 구조를 통해 전원 ON, 안전 종료 요청, 종료 완료 후 전원 차단이라는 동작을 명확하게 구현할 수 있음.
